## 🚀 البدء السريع

### المتطلبات
- Node.js 18+
- PostgreSQL 14+
- Redis (للـ Cache والـ Jobs)

### التثبيت المحلي

```bash
# استنساخ المستودع
git clone https://github.com/mizanaierp-spec/Mizan-AI.git
cd Mizan-AI

# تثبيت الحزم
npm install

# إعداد قاعدة البيانات
npm run db:migrate
npm run db:seed

# تشغيل النظام
npm run dev
```

## 🔒 الصلاحيات (11 دور)

1. **مدير النظام** - تحكم كامل
2. **مدير الشركة** - إدارة الشركة والإعدادات
3. **محاسب** - العمليات المحاسبية الكاملة
4. **مبيعات** - فواتير البيع فقط
5. **مشتريات** - فواتير الشراء فقط
6. **أمين مخزن** - إدارة المخزون
7. **موارد بشرية** - إدارة الموظفين والرواتب
8. **أمين صندوق** - العمليات النقدية
9. **مراقب** - قراءة كاملة + تحليل
10. **مستخدم قراءة فقط** - عرض البيانات فقط
11. **وكيل AI** - تنفيذ عمليات محددة
