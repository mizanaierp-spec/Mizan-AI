# Mizan AI - Frontend

واجهة المستخدم لنظام محاسبة Mizan AI الذكي

## الميزات

- 🎨 واجهة مستخدم حديثة وسهلة الاستخدام
- 🔐 نظام مصادقة آمن
- 📊 لوحة تحكم شاملة
- 💼 إدارة الحسابات والقيود
- 📈 تقارير مالية متقدمة
- 🌍 دعم اللغة العربية والتوجيه من اليمين لليسار (RTL)
- 📱 واجهة استجابة وتتكيف مع جميع الأجهزة

## المتطلبات

- Node.js 16+
- npm أو yarn

## التثبيت

```bash
cd frontend
npm install
```

## التطوير

لتشغيل خادم التطوير:

```bash
npm run dev
```

ستتمكن من الوصول للتطبيق على: `http://localhost:3000`

بيانات دخول تجريبية:
- البريد: `admin@mizan.local`
- كلمة المرور: `Admin@123`

## البناء

لبناء التطبيق للإنتاج:

```bash
npm run build
```

سيتم إنشاء مجلد `dist` يحتوي على الملفات الجاهزة للنشر.

## الصفحات الرئيسية

- **Dashboard** - لوحة التحكم الرئيسية
- **Chart of Accounts** - دليل الحسابات
- **Journal Entries** - القيود اليومية
- **Trial Balance** - ميزان المراجعة
- **Reports** - التقارير المالية
- **Users** - إدارة المستخدمين
- **Inventory** - إدارة المخزون
- **Sales** - المبيعات
- **Purchases** - المشتريات
- **Payroll** - الرواتب
- **Assets** - الأصول الثابتة
- **Bank** - البنوك والحسابات

## البنية

```
frontend/
├── public/
├── src/
│   ├── pages/          # صفحات التطبيق
│   ├── App.jsx         # الكومبوننت الرئيسي
│   ├── main.jsx        # نقطة الدخول
│   └── styles.css      # الأنماط العامة
├── index.html          # ملف HTML الرئيسي
├── package.json        # اعتماديات المشروع
└── vite.config.js      # إعدادات Vite
```

## التقنيات المستخدمة

- **React 18** - مكتبة واجهات المستخدم
- **React Router** - إدارة التوجيه
- **Vite** - أداة البناء السريعة
- **CSS3** - التنسيق والتصميم
